# 服务查询页面验收场景

范围：REQ-SVC、REQ-QUERY、REQ-AUTH、REQ-EXP、REQ-STATE。

| ID | 场景 | 预期结果 | 需求 |
|---|---|---|---|
| AC-SVC-001 | 查询协议和单端口 | 返回同一服务项中协议相同且范围包含该端口的结果 | REQ-SVC-005～006 |
| AC-SVC-002 | 查询协议和端口范围 | 返回同一服务项中协议相同且范围相交的结果 | REQ-SVC-005～006 |
| AC-SVC-003 | 查询 TCP ANY | 只匹配 TCP 全端口语义，不匹配 UDP ANY | REQ-SVC-002～003 |
| AC-SVC-004 | 查看服务查询结果 | 显示所属关系、源/目标系统、有效状态和交集提示 | REQ-QUERY-003、REQ-SVC-007 |
| AC-SVC-005 | 尝试从查询页维护服务项 | 页面保持只读，并引导到所属关系编辑页 | REQ-SVC-004、REQ-QUERY-003 |
| AC-SVC-006 | 受限用户查询或导出 | 无权关系及服务项不出现在结果、选项或导出中 | REQ-AUTH-001～003、REQ-EXP-001 |
| AC-SVC-007 | 翻页、排序、刷新或分享 URL | 服务端结果和 URL 中的查询状态一致 | REQ-QUERY-002 |
