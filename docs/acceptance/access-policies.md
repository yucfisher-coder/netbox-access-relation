# 访问关系页面验收场景

范围：REQ-POL、REQ-SVC、REQ-QUERY、REQ-AUTH、REQ-STATE、REQ-EXP。

| ID | 场景 | 预期结果 | 需求 |
|---|---|---|---|
| AC-POL-001 | 创建源、目标相同或名称重复的关系 | 明确报错且不写入 | REQ-POL-001、REQ-TXN-002 |
| AC-POL-002 | 修改系统地址 | 引用关系立即展示两端系统当前全部地址 | REQ-POL-002 |
| AC-POL-003 | 创建未来、当前或过期关系 | 分别显示未生效、有效或已失效 | REQ-POL-003～004、REQ-STATE-001 |
| AC-POL-004 | 提前终止关系 | 失效时间更新，状态同步变化并写入变更记录 | REQ-POL-003～004、REQ-AUDIT-001 |
| AC-POL-005 | 添加重复、空端口或越界服务项 | 明确报错；ANY 与空端口不混同 | REQ-SVC-001～003 |
| AC-POL-006 | 同一关系存在重叠服务项 | 允许保存并提示交集，不合并原始项 | REQ-SVC-007 |
| AC-POL-007 | 同时筛选协议和端口 | 两个条件必须由同一服务项满足 | REQ-SVC-005 |
| AC-POL-008 | 查询单端口或端口范围 | 分别按包含或相交规则返回 | REQ-SVC-006 |
| AC-POL-009 | 使用多字段、多值组合筛选并刷新页面 | 字段间 AND、同字段 OR，URL 状态保持 | REQ-QUERY-001～002 |
| AC-POL-010 | 筛选后执行两种 CSV 导出 | 字段口径正确，导出全部匹配行且权限范围与页面一致 | REQ-EXP-001～002、REQ-AUTH-001 |
| AC-POL-011 | 访问关系提交发生字段校验、服务项校验、权限拒绝或保存异常 | 页面明确提示失败并定位到字段、服务项行或页面级错误；保留有效输入且不产生部分写入 | REQ-POL-006、REQ-TXN-002、REQ-AUTH-003 |
| AC-POL-012 | 打开访问关系列表和详情并修改任一端系统地址 | 两端立即展示当前原生对象类型、地址或范围、VRF、匹配 Prefix、安全区域和解析状态；有权限时可跳转原生对象 | REQ-POL-002、REQ-POL-007、REQ-AUTH-001～003 |
| AC-POL-013 | 在访问关系列表筛选面板输入分类 | 页面显示独立“分类”筛选行，仅返回分类精确匹配的访问关系，并将条件保留在 URL | REQ-QUERY-001～002 |
