# 工作簿导入验收场景

范围：REQ-IMP、REQ-AUTH、REQ-TXN、REQ-AUDIT。

| ID | 场景 | 预期结果 | 需求 |
|---|---|---|---|
| AC-IMP-001 | 上传含多项错误的工作簿 | 一次预检列出工作表、位置、字段、原值和原因，不写入任何对象 | REQ-IMP-005、REQ-TXN-002 |
| AC-IMP-002 | 预检无错误但未确认 | 不执行正式写入 | REQ-IMP-006 |
| AC-IMP-003 | 正式写入中任一对象失败 | 整批回滚，不产生部分对象 | REQ-IMP-006、REQ-TXN-002 |
| AC-IMP-004 | 重复提交相同数据或遇到同名正式对象 | 不重复创建，也不自动覆盖、更新或删除 | REQ-IMP-006、REQ-IMP-009 |
| AC-IMP-005 | 系统名模糊、地址集合不一致或服务无法解析 | 预检明确报错，不猜测匹配 | REQ-IMP-002～003、REQ-IMP-008 |
| AC-IMP-006 | 工作簿区域与实时解析不一致 | 只报告差异，不创建选项或回填 Prefix | REQ-IMP-004 |
| AC-IMP-007 | 无权限用户预检或确认导入 | 按发起用户拒绝且不泄露无权对象 | REQ-AUTH-001～003、REQ-TXN-002 |
| AC-IMP-008 | 导入处理结束 | 原文件和预检临时证据不长期保存，最终对象保留原生变更记录 | REQ-IMP-007、REQ-AUDIT-001 |
| AC-IMP-009 | 下载并填写业务系统批量导入模板 | 模板含业务系统、系统别名和系统地址三个版本化工作表，并以规范名建立关联 | REQ-IMP-010～011 |
| AC-IMP-010 | 地址精确匹配一个已有 IPAM 对象或不存在 | 预检分别生成“关联已有”或“创建并关联”计划 | REQ-IMP-012 |
| AC-IMP-011 | 地址匹配歧义、VRF 不明确、字段冲突或权限不足 | 预检在对应行明确报错，不猜测对象且整批不可确认 | REQ-IMP-005、REQ-IMP-012 |
| AC-IMP-012 | 文件包含完全重复行和多种待执行操作 | 预检分别汇总新增、关联、创建并关联、跳过重复和错误，并可查看逐行计划 | REQ-IMP-013 |
| AC-IMP-013 | 导入文件试图修改或删除已有对象 | 预检拒绝；首期导入只允许新增缺失对象与关联 | REQ-IMP-009、REQ-IMP-014 |
