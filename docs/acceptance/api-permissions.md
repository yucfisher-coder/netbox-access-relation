# API 与权限验收场景

范围：REQ-AUTH、REQ-API、REQ-AUDIT、REQ-TXN。

| ID | 场景 | 预期结果 | 需求 |
|---|---|---|---|
| AC-API-001 | 查询核心对象集合和详情 | 只返回当前用户有权查看的对象并正确分页 | REQ-AUTH-001、REQ-API-001 |
| AC-API-002 | 使用与页面相同的筛选条件 | API 与页面返回相同权限范围和业务语义 | REQ-API-001～002 |
| AC-API-003 | 通过 API 创建、修改或删除对象 | 使用与页面和导入相同的业务校验 | REQ-API-002 |
| AC-API-004 | 无插件权限或原生 IPAM 权限不足 | 请求被拒绝，不产生部分写入 | REQ-AUTH-002、REQ-TXN-002 |
| AC-API-005 | 受限用户访问计数、选项或错误路径 | 不泄露无权对象是否存在 | REQ-AUTH-003 |
| AC-API-006 | 成功执行业务对象变更 | 原生变更记录包含发起用户和最终变更 | REQ-AUDIT-001 |
| AC-API-007 | 触发认证或限流边界 | 使用 NetBox 统一认证和限流响应 | REQ-AUTH-001 |
