# UI 公共验收场景

范围：REQ-UI、REQ-AUTH、REQ-STATE、REQ-EXP。

| ID | 场景 | 预期结果 | 需求 |
|---|---|---|---|
| AC-UI-001 | 从导航进入页面并沿对象链接跳转 | 导航、面包屑和目标对象正确 | REQ-UI-001～002 |
| AC-UI-002 | 切换中英文并检查标准表单区域 | 标签一致，标准字段不重复渲染 | REQ-UI-001 |
| AC-UI-003 | 筛选、排序、翻页、刷新和分享 URL | 页面状态与 URL 一致 | REQ-QUERY-002 |
| AC-UI-004 | 分别制造空数据、无匹配、无权限和计算异常 | 四类状态可区分且有文本说明 | REQ-STATE-002 |
| AC-UI-005 | 受限用户访问列表、详情、计数、下钻和导出 | 所有表面使用同一对象范围且不泄露无权对象 | REQ-AUTH-001～003 |
| AC-UI-006 | 导出当前视图和全部数据 | 字段、筛选、排序、总行数和权限符合对应导出需求 | REQ-EXP-001～003 |
