# 1.3.3 发布说明

发布日期：2026-10-13

## 变更

- 修复移除服务项未提交删除标记的问题，支持一次保存替换最后一个服务项，并保留禁止删空保护。
- ANY 必须是访问关系唯一的服务项，页面、API、模型及工作簿导入统一拒绝 ANY 与其他端口共存。
- 补齐访问关系及业务系统编辑页按钮、ANY 说明、影响提示和校验消息的中英文翻译。

- 修复访问关系仅修改分类、业务系统仅修改名称时，空白内联新增行阻止保存的问题；保留并发修改校验，未修改的原生 IPAM 对象不再重复写入。
- 业务系统地址的状态选项按 NetBox 原生 Prefix、IPAddress、IPRange 定义切换，IPRange 不再提供容器状态。
- 服务查询支持协议和端口升降序，端口按数字排序，分页和 CSV 导出保留筛选及排序。
- 服务查询与区域矩阵的导航、页面、筛选、区域状态和 CSV 导出支持中英文切换。
- 修正 NetBox 4.7.2 基础镜像摘要和跨平台构建校验，验证脚本支持独立生产验证镜像标签。
- 固定本机生产验证环境的同步更新和资源清理约定，保留仍需使用的持久数据。

## 验证与兼容性

新增编辑表单回归覆盖，完整 27 项自动化测试通过；在本机生产验证环境完成浏览器删除、替换、ANY 互斥和中英文切换验收。无新增数据库迁移，与 1.3.2 数据库结构兼容。

升级前备份数据库与附件，将应用镜像更新为 `netbox-access-relations:1.3.3`，再完成迁移检查、健康检查及业务验收。
