# 1.3.4 发布说明

发布日期：2026-10-14

## 变更

- 修复确认工作簿导入时，原生 IPAM 字段错误被绑定到上传表单不存在的字段而导致服务器异常的问题；失败时显示校验信息，整个导入事务回滚。
- `ip_address` 必须显式填写掩码，不接受 `/0`；`ip_range` 起止地址均必须显式填写掩码，且 IP 版本、掩码一致。创建与匹配原生 IPRange 时保留掩码，模板字段说明和示例同步更新。
- 导入预检执行原生 IPAM 校验，提前报告重复地址、已填充地址范围等错误。
- 业务系统、访问关系列表增加复选框与批量修改、批量删除入口，沿用 NetBox 对象权限和关联保护。
- 增加列表删除、地址关联清理、共享地址标记、批量操作与导入校验的回归覆盖。

## 验证与兼容性

完整 38 项自动化测试通过；浏览器验收覆盖列表行菜单删除、两个列表的勾选、批量修改和批量删除。用户反馈的偶发删除问题未再次复现，未变更单条删除逻辑。

无新增数据库迁移，与 1.3.3 数据库结构兼容。旧工作簿中缺少掩码的 IPAddress/IPRange 行需要补齐；请重新下载导入模板。

升级前备份数据库与附件，将应用镜像更新为 `netbox-access-relations:1.3.4`，完成迁移检查、健康检查及业务验收。验证镜像使用独立的 `1.3.4-verify` 标签。
