# 1.2.1 发布说明

发布日期：2026-09-30

## 修复

- 修复 Windows PowerShell 运维脚本仍引用已删除 `compose/` 目录的问题，统一使用根目录的 Compose 文件。
- 恢复 Linux/macOS bash 脚本的可执行位，使文档中的脚本入口可直接执行。

## 变更

- 明确插件包、Docker 开发环境与已验证 Linux 生产环境的跨平台支持边界。

## 升级说明

- 本版本不包含数据库迁移；数据结构基线仍为 `0001`～`0005`，可直接从 `1.2.0` 升级。
- 将应用镜像或 `NETBOX_PRODUCTION_IMAGE` 更新为 `netbox-access-relations:1.2.1`，再执行常规迁移检查和服务重启。
