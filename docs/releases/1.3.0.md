# 1.3.0 发布说明

发布日期：2026-10-01

## 主要变更

- 服务查询按相同协议与端口表达式聚合，直接展示关联目标系统和访问关系；单端口筛选会命中包含该端口的范围。
- ANY 改为全协议表达式，覆盖所有 TCP 和 UDP 端口；查询、重叠判断、访问关系列表与详情、表单及 XLSX 导入均采用同一语义。
- 访问关系编辑页勾选“全协议 ANY”后不再要求协议或端口；导入模板提供 ANY 示例，ANY 的 protocol 列可为空。

## 升级说明

- 本版本包含迁移 `0006_global_any_services`。升级前请完成数据库备份；执行 `manage.py migrate` 后再启动或重启 NetBox web 与 worker。
- 迁移会将历史 ANY 规范化为单个全协议服务；同一访问关系下存在多个历史 ANY 时保留最早创建的记录。
- 将应用镜像或 `NETBOX_PRODUCTION_IMAGE` 更新为 `netbox-access-relations:1.3.0`，并完成服务查询、访问关系录入与 XLSX 导入验收。
