# 1.0.2 发布说明

发布日期：2026-09-26

## 改进

- 访问关系列表直接展示服务能力：端口服务使用 `协议_端口` 或 `协议_端口范围`，任意端口显示为 `ANY`。
- 调整分类、服务项及 IPAM 信息列的布局；安全区域结果直接显示在源端和目标端 IPAM 信息中。

## 修复

- CSV 导出添加 UTF-8 BOM，确保 Excel 正确识别中文。
- 访问关系 CSV 导出的 IPAM 信息仅包含地址与可选 VRF，不包含安全区域或地址类型标签；服务项使用真实换行。

## 兼容性

- 不包含数据库迁移；与 1.0.0 数据库结构基线兼容。
- 支持 NetBox 4.7.x 和 Python 3.12 或更高版本。
