# 1.3.2 发布说明

发布日期：2026-10-11

## 变更

- 部署入口统一为 Docker Compose；脚本可选，已有匹配架构的运行镜像可跳过构建。
- 镜像、备份及恢复命令集中到[关键命令指南](../guides/deployment/commands.md)，解释构建与运行所需的 Python 环境。
- 离线源码包包含完整已跟踪项目，排除配置密钥与业务数据；精简平台指南的重复流程。
- 备份期间暂停写入，增加兼容性元数据与校验；修复 Windows 二进制备份传输方式。
- 回归测试使用独立 Compose 项目，结束后清理测试资源。

## 兼容性与升级

无新增数据库迁移，与 1.3.1 数据库结构兼容。升级前备份数据库与附件并演练恢复，将应用镜像更新为 `netbox-access-relations:1.3.2`，再启动并完成健康、迁移及业务验收。

部署不要求宿主机安装 Python；离线源码构建需要提前准备 Python 构建镜像、NetBox 基础镜像和依赖 wheel。
