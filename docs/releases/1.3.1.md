# 1.3.1 发布说明

发布日期：2026-10-02

## 变更

- NetBox 基线升级为 4.7.2，开发、生产、离线构建和镜像锁定均使用官方 `v4.7.2-5.1.1` 多架构镜像。
- API 与 XLSX 导入增加对象级权限校验；不可见对象不会通过导入预检错误暴露存在性。
- CSV 导出防止电子表格公式注入；XLSX 导入限制工作表数据行数及单元格长度。

## 兼容性与升级

- 不包含新的数据库迁移，与 1.3.0 数据库结构兼容。
- 从 NetBox 4.7.0 升级到 4.7.2 的最短步骤见[Docker 部署指南](../guides/deployment/docker.md#从-netbox-470-升级到-472)。
- 将应用镜像或 `NETBOX_PRODUCTION_IMAGE` 更新为 `netbox-access-relations:1.3.1`，再完成迁移检查和关键功能验收。
