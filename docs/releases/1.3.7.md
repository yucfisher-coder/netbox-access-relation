# 1.3.7 发布说明

发布日期：2026-11-21

## 修复

- 访问关系详情页增加独立服务项面板，展示 TCP/UDP 协议、单端口、端口范围和 ANY，点击端口可进入服务详情。
- 仅显示当前访问关系的服务项，保留服务项查看权限和对象级权限限制。
- 无可见服务项时显示空状态。

## 兼容与升级

无新增数据库迁移，与 1.3.6 数据库结构兼容。升级前备份数据库和附件，将应用与 worker 更新为 `netbox-access-relations:1.3.7`，执行迁移检查和健康检查。

本地生产验证使用独立镜像 `netbox-access-relations:1.3.7-verify`，访问地址为 http://127.0.0.1:8001。
