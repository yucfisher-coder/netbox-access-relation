# 1.1.1 发布说明

发布日期：2026-09-29

## 修复

- 修复访问关系手动添加或编辑时，表单清洗阶段可能因父类未返回 `cleaned_data` 而跳转 500 错误页的问题。现在字段或服务项校验失败会保留在当前页面并显示明确提示。

## 改进

- 访问关系服务项编辑器新增“移除服务”按钮。用户误点“添加服务”后可移除多余行；编辑已有关系时，移除操作会删除对应的已保存服务项。
- 当页面仅剩一行服务项时，移除按钮不可用，确保表单始终保留一行可编辑服务项并符合“至少一个服务项”的约束。

## 兼容性与升级

- 不包含数据库迁移；数据结构基线仍为 `0001`～`0005`，与 `1.1.0` 兼容。
- 支持 NetBox 4.7.x 和 Python 3.12 或更高版本。
- 升级时安装 `1.1.1` wheel，按 `production-deployment.md` 切换 `NETBOX_PRODUCTION_IMAGE` 为 `netbox-access-relations:1.1.1`，执行 `manage.py migrate`、`collectstatic --no-input` 后重启 NetBox web 和 worker 服务。
