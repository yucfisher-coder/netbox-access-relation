# 1.3.5 发布说明

发布日期：2026-10-17

## 变更

- 业务系统和访问关系的快速搜索与顶部原生全局搜索统一匹配：系统名称、别名、访问关系名称、分类和关联 Prefix、IPAddress、IPRange 地址文本。
- 描述、自定义字段、有效期、协议及端口不参与快速搜索和插件全局索引；原有专用筛选条件继续保留，IP 网段包含关系仍使用专用 IP 筛选。
- 搜索按关联分组查询，避免多值关联相乘；索引同步覆盖系统、别名、地址关联及原生 IPAM 地址的修改。
- 表头复选框补齐全选、未选、部分选择三态，支持表头切换与逐项选择同步。HTMX 排序、分页后清理过期的跨页选择确认和批量操作状态。
- 保留 NetBox 原生批量操作、权限校验与跨页选择确认流程；复选框增强仅作用于插件页面。

## 验证与兼容性

41 项自动化测试通过，包含搜索字段正反向验证及 3000 个业务系统、2000 条访问关系规模测试。每个系统包含一个别名和 IP 时，生成 23000 条索引约 12.2 秒；系统别名查询约 11.9 ms、访问关系别名查询约 15.7 ms、访问关系 IP 查询约 17.6 ms、全局别名查询约 12.7 ms。以上为本机单次数据库查询测试，不包含完整页面加载时间，不代表并发生产负载下的响应保证。

Playwright + Chrome 验证桌面、手机、表头三态、批量提交选中值及 HTMX 排序和分页。访问关系列表样例只有一行，部分选择状态在多行业务系统列表验证。用户人工验收通过。

无新增数据库迁移，与 1.3.4 数据库结构兼容。升级前备份数据库及附件，将应用镜像更新为 `netbox-access-relations:1.3.5`，执行迁移检查与健康检查。已有对象需执行：

```sh
PRODUCTION_ENV_FILE=.env.production docker compose --env-file .env.production -f docker-compose.prod.yml exec netbox \
  /opt/netbox/venv/bin/python /opt/netbox/netbox/manage.py reindex netbox_access_relations
```

保持 worker 运行，以处理后续索引更新。验证镜像使用独立的 `1.3.5-verify` 标签。
