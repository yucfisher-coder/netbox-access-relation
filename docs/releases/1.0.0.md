# 1.0.0 首个生产版本

发布日期：2026-09-22。

## 范围

- 业务系统、别名及 Prefix、IPAddress、IPRange 地址关联维护；
- 实时安全区域解析证据与合并部署标记；
- 有方向、有有效期的访问关系及 TCP/UDP 服务项；
- 访问关系组合筛选、只读服务查询和区域矩阵；
- 业务系统及访问关系版本化 XLSX 预检、确认和事务导入；
- 权限范围内的 CSV 导出；
- NetBox 原生页面、对象权限、变更记录和 REST 路由。

## 数据结构基线

生产首发包含且仅包含 `0001_initial` 至 `0005_accesspolicy_policyservice_and_more`。本次从开发版
提升至 `1.0.0` 不新增迁移。剩余功能只允许在不改变这一基线的前提下进入 `1.0.x`；任何模型或
数据库约束变化必须进入新的升级版本并附恢复验证。

## 已知限制

- 核心对象 API 已存在，但 API 与页面/导入业务服务复用及细粒度权限仍需继续专项加固。
- 区域矩阵和服务查询尚需在真实生产规模上复核性能。
- 区域矩阵和服务查询的真实生产规模性能复核，以及 API 专项加固，将在不改变当前数据结构的 `1.0.x` 中继续完成。

## 发布判定

`docs/verification.md` 中的 104 项完整测试、迁移漂移检查、linux/arm64 不可变镜像离线启动及
隔离备份恢复门禁均已通过，1.0.0 标记为已发布。当前制品适用于已验证的 linux/arm64；其他
生产架构必须使用同一锁定输入原生重建，并在切流前重复启动和恢复演练。
