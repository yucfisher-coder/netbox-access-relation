# 1.2.0 发布说明

发布日期：2026-09-30

## 改进

- 修正 CI 与发布工作流的插件构建目录，使其从仓库根目录构建发行 wheel。
- 完善项目入口文档：补齐兼容性、贡献、变更日志、历史发布说明、许可证和安全策略入口，并明确本地首次登录的管理员账号准备方式。

## 兼容性与升级

- 不包含数据库迁移；数据结构基线仍为 `0001`～`0005`，可直接从 `1.1.1` 升级。
- 支持 NetBox 4.7.x 和 Python 3.12 或更高版本。
- 升级时安装 `1.2.0` wheel，按 `production-deployment.md` 切换 `NETBOX_PRODUCTION_IMAGE` 为 `netbox-access-relations:1.2.0`，执行 `manage.py migrate`、`collectstatic --no-input` 后重启 NetBox web 和 worker 服务。
