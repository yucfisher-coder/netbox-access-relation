# 1.1.0 发布说明

发布日期：2026-09-28

## 改进

- 合并 Compose 定义：删除 `compose/` 目录，根目录 `docker-compose.yml` 与 `docker-compose.prod.yml` 成为唯一来源；bash 脚本、PowerShell 封装与 CI 均指向同一份文件，消除双份维护与漂移风险。
- 整理文档体系：备份、恢复与迁移相关内容合并为单一运维手册 `production-deployment.md`；新增 `code-structure.md`（代码结构说明）与 `development.md`（本地开发指南）。

## 移除

- 删除无人引用的 `config/plugins-disabled.py`。
- 精简 `locks/images.md` 中过时的本地镜像 ID 与失败构建记录，仅保留不可变镜像引用锁表。

## 兼容性

- 不包含数据库迁移；数据结构基线仍为 `0001`～`0005`，与 `1.0.0` 兼容，可直接升级镜像。
- 支持 NetBox 4.7.x 和 Python 3.12 或更高版本。
- 生产镜像标签、wheel 文件名与离线包目录名随版本更新为 `1.1.0`；升级时按 `production-deployment.md` 的升级流程切换 `NETBOX_PRODUCTION_IMAGE` 即可。
