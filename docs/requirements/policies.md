# 访问关系

来源基线：R06。状态：已确认。

| ID | 需求 |
|---|---|
| REQ-POL-001 | `AccessPolicy` 是有方向的关系，包含全局唯一名称、分类、源系统、目标系统、有效期、状态和备注；源系统与目标系统不能相同。 |
| REQ-POL-002 | 关系始终使用两端系统当前的全部地址，不选择地址子集。 |
| REQ-POL-003 | 关系默认长期有效，可设置生效和失效时间并提前终止。 |
| REQ-POL-004 | 状态根据有效期自动显示未生效、有效或已失效。 |
| REQ-POL-005 | 地址变化立即影响引用该系统的关系；修改前显示受影响关系，删除系统前必须先处理引用。 |
| REQ-POL-006 | 新增或编辑访问关系失败时，页面必须明确提示失败，并尽量定位到关系字段或服务项行；校验失败不得清空用户已填写的有效内容，权限或保存异常不得产生部分写入。 |
| REQ-POL-007 | 访问关系列表和详情必须随源、目标系统同时展示其当前 IPAM 证据，包括原生对象类型、地址或范围、VRF、匹配 Prefix、安全区域及区域解析状态；用户有权限时提供原生对象链接，不复制这些值到访问关系。 |

关系内服务项见 `services.md`；查询与矩阵见 `query-presentation.md`。
