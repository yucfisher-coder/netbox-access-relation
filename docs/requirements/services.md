# 服务项与匹配

来源基线：R07，以及 R10 中的查询组合要求。状态：已确认。

| ID | 需求 |
|---|---|
| REQ-SVC-001 | 一个访问关系包含一个或多个不可重复服务项。 |
| REQ-SVC-002 | 首期协议仅 TCP、UDP；端口支持 ANY、单端口和 1–65535 闭区间。 |
| REQ-SVC-003 | ANY 代表所有 TCP 和 UDP 端口，不区分协议；空端口不等于 ANY。 |
| REQ-SVC-004 | 服务项归属于具体访问关系，不建立跨关系复用目录。 |
| REQ-SVC-005 | 协议和端口筛选必须由同一个服务项同时满足。 |
| REQ-SVC-006 | 单端口查询匹配包含该端口的服务项；范围查询匹配与查询范围相交的服务项。 |
| REQ-SVC-007 | 服务交集只提示，不阻止保存，也不合并原始服务项。 |
| REQ-SVC-008 | 手动录入和编辑关系时，服务项编辑器必须支持逐行新增和移除；移除操作不得留下空服务项，且界面至少保留一行可编辑服务项。 |

服务别名只用于导入解析；确认映射后保存数字端口，无法解析时阻止导入。该流程见
`import-export.md`。
