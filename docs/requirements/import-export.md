# 导入与导出

来源基线：R08–R10。状态：已确认。

## 工作簿导入

| ID | 需求 |
|---|---|
| REQ-IMP-001 | 手工维护是主要入口，导入只用于批量辅助；网页、API 和导入复用同一业务校验。 |
| REQ-IMP-002 | 工作簿系统必须精确匹配规范名或人工确认别名；不自动创建、模糊匹配或猜测合并。 |
| REQ-IMP-003 | 访问关系行中的地址必须与系统当前完整地址集合一致，否则先人工修正或拆分系统。 |
| REQ-IMP-004 | 工作簿区域只核对实时派生区域，不创建选项、不回填 Prefix；无法严格解析时留空。 |
| REQ-IMP-005 | 上传后先整批预检；错误逐项显示工作表、单元格或行号、字段、原始值和原因；任一错误阻止写入。 |
| REQ-IMP-006 | 无错误后仍需用户明确确认；正式写入使用单一事务并整体回滚；重复提交不得产生重复对象。 |
| REQ-IMP-007 | 原始文件处理后不保存；预检结果只服务当前操作，不新增 ImportBatch、SourceRow、ValidationIssue 或地址证据缓存等长期模型。 |
| REQ-IMP-008 | 分类、源/目标系统、协议、目标端口和备注按列映射；服务别名确认后保存数字端口；重复行或无法解析的服务明确报错。 |
| REQ-IMP-009 | 同名正式对象不得由导入自动覆盖、更新或删除。 |
| REQ-IMP-010 | 业务系统批量导入使用带版本号的 XLSX 模板，分别提供“业务系统”“系统别名”“系统地址”工作表；工作表之间以业务系统规范名关联，不要求用户填写数据库主键。 |
| REQ-IMP-011 | “系统地址”工作表每行包含业务系统规范名、对象类型、地址值、VRF 及创建原生对象所需的可选状态和描述；不设置容易误用的新增、更新、删除操作列。 |
| REQ-IMP-012 | 系统地址导入按“对象类型 + 规范化地址值 + VRF”精确解析：唯一已有原生对象生成“关联”计划，不存在时生成“创建并关联”计划；歧义、字段冲突或权限不足均作为预检错误，不猜测选择。 |
| REQ-IMP-013 | 预检结果按新增系统、新增别名、关联已有地址、创建并关联地址、跳过的完全重复项和错误分别汇总，并允许展开查看逐行处理计划；只有无错误且用户确认后才能整批写入。 |
| REQ-IMP-014 | 首期批量导入只新增缺失对象和关联；不得更新或删除已有业务系统、别名、原生 IPAM 对象或地址关联。修订与解除关联通过业务系统页面完成。 |

### 业务系统导入模板

模板列固定如下；新增版本只能通过模板版本号和兼容性检查演进，不按用户上传的任意列名猜测映射。

| 工作表 | 必填列 | 可选列 | 行语义 |
|---|---|---|---|
| 业务系统 | `system_name` | `status`、`description`、`comments` | 每行新增一个尚不存在的业务系统；已存在的规范名只作为后续工作表引用，不覆盖字段 |
| 系统别名 | `system_name`、`alias` | 无 | 为精确匹配的业务系统新增别名；完全重复项跳过，命名空间冲突报错 |
| 系统地址 | `system_name`、`object_type`、`address` | `range_end`、`vrf_rd`、`native_status`、`native_description` | `object_type` 仅允许 `prefix`、`ip_address`、`ip_range`；IPRange 用 `address` 表示起点并要求 `range_end`，其他类型不得填写 `range_end`；空 `vrf_rd` 表示全局 VRF |

系统地址值在预检时先规范化，再以对象类型、规范化地址（IPRange 使用起止值）和 `vrf_rd` 精确匹配。
模板不包含数据库主键、区域值、操作类型、更新标记或删除标记。区域始终实时派生；“关联已有”与
“创建并关联”由预检结果决定，并在用户确认前明确展示。

不提交原业务数据文件或真实业务行；权限、
事务和审计的统一规则见 `authorization-api.md`。

## 数据导出

| ID | 需求 |
|---|---|
| REQ-EXP-001 | “当前视图”CSV 保留当前筛选和排序，使用当前展示列，导出全部匹配行而非当前分页。 |
| REQ-EXP-002 | “全部数据”CSV 保留当前筛选，导出该对象全部可导出字段；排除选择框、操作按钮和明确排除的内部字段。 |
| REQ-EXP-003 | 可选 ExportTemplate 仅对有权查看模板和业务对象的用户开放；首期不建设独立 XLSX 导出引擎。 |

导出对象范围统一遵循 `authorization-api.md`，不在本文件另设权限口径。
