# 页面、查询与区域矩阵

来源基线：R10。状态：已确认。

## 页面与入口

| ID | 需求 |
|---|---|
| REQ-UI-001 | 使用 NetBox 原生导航、列表、详情、表单、筛选、分页、权限按钮和变更记录，不建设 SPA。 |
| REQ-UI-002 | 顶级入口为业务系统、访问关系、服务查询和区域矩阵；安全区域只读查询并跳转 Prefix；导入导出是对象页面操作，不设独立导入记录或通用 IP 搜索主菜单。 |

## 查询

| ID | 需求 |
|---|---|
| REQ-QUERY-001 | 访问关系支持按名称、分类、源/目标/任一系统、IP、区域、协议、端口和有效状态组合筛选。 |
| REQ-QUERY-002 | 不同字段之间为 AND，同一字段多个值为 OR；筛选条件保存在 URL。 |
| REQ-QUERY-003 | 服务查询是跨访问关系的只读查询，按相同协议与端口表达式聚合，返回关联目标系统和访问关系。ANY 作为覆盖全部 TCP/UDP 端口的单一表达式展示。 |

协议与端口的匹配语义只由 `services.md` 定义。

## 区域矩阵

| ID | 需求 |
|---|---|
| REQ-MATRIX-001 | 以源区域为行、目标区域为列展示访问关系分布。 |
| REQ-MATRIX-002 | 每个单元格按访问关系去重计数；同一关系可进入多个真实区域组合。 |
| REQ-MATRIX-003 | 未设置、未匹配和歧义分别作为独立行或列。 |
| REQ-MATRIX-004 | 非零单元格可下钻到保留矩阵筛选、源区域和目标区域条件的关系列表。 |
| REQ-MATRIX-005 | 区域矩阵筛选项使用统一响应式栅格；同一断点下标签、输入控件及操作按钮须横向成行、纵向对齐，窄屏按完整字段逐项换行。 |

页面具体布局和操作见 `ui/`，本文件不定义视觉实现。
