# UI 公共规格

需求引用：REQ-UI-001～002、REQ-AUTH-001～003、REQ-STATE-001～002、REQ-EXP-001～003、
REQ-IMP-005～007、REQ-IMP-010～014。

## 信息架构

插件使用 NetBox Community 4.7.0 原生界面能力，不建设独立前端应用或 SPA。顶级导航为业务系统、
访问关系、服务查询和区域矩阵。

安全区域不是独立可编辑对象；展示值来自 Prefix 的 `security_zone` 自定义字段，并可跳转到原生
Prefix 页面。不设置通用 IP 搜索、通用导入中心、导入记录、独立系统别名或独立服务项顶级入口。
别名、系统地址和服务项分别在业务系统或访问关系页面维护；导入导出是对象页面操作。

## 页面框架

- 使用原生导航、面包屑、对象列表、详情、表单、筛选、分页、权限按钮和变更记录。
- 列表页只设置有明确业务作用的页签，筛选条件、排序、页码和每页数量保存在 URL。
- 非法筛选条件明确提示，不静默忽略。
- 对象名称及关联的系统、地址、Prefix 和区域提供可访问的详情链接。
- 多个地址或区域直接可读，可换行或折叠展开，不能只在悬停时显示。
- 空数据、无匹配、无权限和计算异常使用不同状态。

## 状态术语

- 关系有效状态显示为未生效、有效或已失效。
- 区域解析状态显示为已匹配、未设置、未匹配或歧义。
- 两类状态不得共用含义含混的标签；区域状态语义只采用 REQ-ZONE-003～006。

## 权限呈现

- 列表、详情、筛选、矩阵、下钻、导出和 API 的可见对象范围一致。
- 新增、编辑、删除、关联地址、导入和提前终止按钮按权限显示。
- 地址操作需要原生 IPAM 权限；无权对象不得通过计数、选项、导出或错误信息泄露。

## 导出交互

- 业务系统和访问关系列表提供“当前视图 CSV”和“全部数据 CSV”。
- 服务查询和区域矩阵提供各自结果导出。
- 当前视图使用展示列并导出全部匹配行；全部数据使用全部可导出字段。
- 选择框、操作按钮和内部字段不导出；ExportTemplate 按模板与业务对象权限显示。

## 导入交互

导入入口位于业务系统或访问关系页面。交互流程为：下载带版本说明的模板、上传、整批预检、展示
错误和警告、用户确认、单事务写入、展示结果和对象链接。

业务系统与地址使用分工作表的 XLSX 模板，访问关系与服务项使用其对应模板；不设置脱离业务页面的
通用导入中心。预检必须展示逐行处理计划，不能用含义模糊的“覆盖”选项让用户同时承担新增、更新和
删除语义。

错误展示包含工作表、行号或单元格、字段、原始值和原因。页面不虚构长期导入批次或来源证据，
手工创建对象也不显示虚假的导入来源。

共同验收场景见 `acceptance/common.md`，页面专属场景见对应验收文件。
