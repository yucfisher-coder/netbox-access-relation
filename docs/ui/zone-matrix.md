# 区域矩阵页面规格

需求引用：REQ-MATRIX-001～004、REQ-ZONE-006、REQ-QUERY-002、REQ-AUTH-001～003、
REQ-EXP-001。

## 页面目标与结构

用源安全区域到目标安全区域的二维矩阵展示访问关系分布。行表示源区域，列表示目标区域，单元格
显示去重关系数；异常区域状态分别成行或列。

同时显示行合计、列合计和去重关系总数。由于一条关系可进入多个区域组合，单元格合计可能大于
关系总数，页面必须解释口径。

## 筛选与下钻

支持按业务系统、协议、单端口或端口范围和关系有效状态筛选。服务匹配采用 REQ-SVC-005～006，
组合和 URL 状态采用 REQ-QUERY-002。

筛选区采用统一响应式栅格：桌面端每行四列，中等宽度每行两列，窄屏每行一列。所有字段标签、
输入控件以及“应用/清除”操作在各行保持相同基线和宽度，不因标签长度或控件类型产生上下错位。

点击非零单元格进入关系列表，保留矩阵筛选及源、目标区域。异常区域下钻显示解析状态、原因和
可追溯的系统地址及 Prefix。零值单元格不提供下钻。

## 性能、权限和导出

- 矩阵由服务端在当前对象权限范围内聚合。
- 区域较多时允许固定表头、横向滚动或按需加载，但不得静默截断。
- 无数据时区分无匹配和无权限。
- CSV 包含源区域、目标区域、关系数和筛选条件说明。

验收场景见 `acceptance/zone-matrix.md`。
