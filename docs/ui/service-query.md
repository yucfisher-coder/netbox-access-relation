# 服务查询页面规格

需求引用：REQ-QUERY-002～003、REQ-SVC-005～007、REQ-EXP-001、REQ-AUTH-001～003。

## 页面目标

提供跨访问关系的只读服务查询，回答哪些关系使用某协议或端口。服务项仍归属于具体访问关系。

## 结果与筛选

结果至少展示协议、端口类型、端口表达、所属关系、源系统、目标系统、关系有效状态和服务交集
提示。关系和两端系统提供详情跳转；使用服务端筛选、排序和分页。

支持按协议、单端口或端口范围、所属关系、源/目标/任一系统和关系有效状态筛选。端口与协议匹配
只采用 REQ-SVC-002～007。页面不提供服务项维护按钮，统一跳转到所属关系编辑页。

## 导出

导出当前筛选结果，至少包含结果展示字段，并应用关系和服务项对象权限。

验收场景见 `acceptance/service-query.md`。
