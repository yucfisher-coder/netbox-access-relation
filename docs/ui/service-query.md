# 服务查询页面规格

需求引用：REQ-QUERY-002～003、REQ-SVC-005～007、REQ-EXP-001、REQ-AUTH-001～003。

## 页面目标

提供跨访问关系的只读服务查询，回答相同协议与端口表达式关联了哪些目标系统和访问关系。服务项仍归属于具体访问关系；查询页只聚合展示，不创建跨关系的服务目录。

## 结果与筛选

结果按协议、端口类型与端口表达精确分组（例如 TCP/443、UDP/53、ANY 或 TCP/8000-8080），每组展示关联目标系统和访问关系名称。ANY 归为单个跨协议的 TCP/UDP 组。目标系统名称提供详情跳转；使用服务端筛选和分页。

筛选区仅提供协议和单端口，避免把查询页变成关系维护页。输入单端口时，匹配该端口所在的一个或多个服务端口范围，以及覆盖所有 TCP/UDP 端口的 ANY 服务项。端口与协议匹配只采用 REQ-SVC-002～007。页面不提供服务项维护按钮。

排序提供协议、端口升序和降序，默认协议升序。端口按起点、终点的数字值排序，同端口按协议排序；ANY 在端口升序时位于数字端口之后，降序时位于之前。协议排序以端口数字值作为次序。排序条件使用 URL 参数 `sort`（`protocol`、`-protocol`、`port`、`-port`），非法值回退协议升序。翻页、刷新、分享和导出保留筛选与排序；更改筛选或排序后回到第一页。

## 导出

导出当前筛选后的聚合结果，按当前排序导出全部匹配组（不限当前页），至少包含协议、端口、目标系统和访问关系名称，并应用关系和服务项对象权限。

验收场景见 `acceptance/service-query.md`。
