# UI 规格入口

版本：2026-09-17

UI 规格已经按公共框架和页面拆分。开发单个页面时只读取公共规格、该页面规格以及需求地图列出的
领域需求。

| 文件 | 内容 |
|---|---|
| `ui/common.md` | 信息架构、页面框架、状态、权限、导入导出和共同验收门槛 |
| `ui/business-systems.md` | 业务系统列表、详情和编辑 |
| `ui/access-policies.md` | 访问关系列表、详情和一体化编辑 |
| `ui/service-query.md` | 只读服务查询 |
| `ui/zone-matrix.md` | 区域矩阵、筛选、下钻和导出 |

UI 文件只定义呈现和交互，不重新定义业务规则。发生冲突时以 `requirements/` 中的领域需求为准。
