# Security Policy

## Supported versions

Security fixes are provided for the latest `1.0.x` release while it remains
compatible with a supported NetBox 4.7 deployment. Older plugin releases and
unlisted NetBox versions are not supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability and do not include
credentials or production data in a report. Until a dedicated private contact
is published, report the issue privately to the package distributor or the
maintainer from whom the release was obtained.

Include the plugin, NetBox, Python, database, and operating-system versions; a
minimal reproduction; the likely impact; and any known mitigations. Reports
should use synthetic data.

Maintainers should acknowledge a report before discussing disclosure timing.
A fix, mitigation, or reason the report is not applicable should be supplied
before public disclosure whenever practical.
